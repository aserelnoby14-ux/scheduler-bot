# Scheduler Bot

بوت تيليجرام على GitHub Actions — يستقبل ملفات من الأدمن، يجدولها، ينشر كل 12 ساعة مع أزرار دعم.

## الإعداد — خطوة بخطوة

### 1. إنشاء البوت على تيليجرام
1. افتح [@BotFather](https://t.me/BotFather)
2. `/newbot` → اسم → username ينتهي بـ `bot`
3. انسخ **Token** (شكله `123456:ABC-DEF...`)

### 2. الحصول على ADMIN_ID
1. افتح [@userinfobot](https://t.me/userinfobot)
2. `/start` → انسخ رقم `Id` (مثال: `123456789`)

### 3. CHANNEL_ID (اختياري — لو النشر في قناة)
1. أنشئ قناة، أضف البوت كأدمن فيها
2. أرسل رسالة في القناة
3. افتح `https://api.telegram.org/bot<BOT_TOKEN>/getUpdates`
4. خد `chat.id` (شكله `-1001234567890`)
5. لو مش عايز قناة — سيبه فاضي (هينشر في الخاص للأدمن)

### 4. رفع على GitHub
1. أنشئ مستودع **Public**
2. ارفع الملفات الخمسة
3. **Settings → Secrets and variables → Actions → New repository secret**:

| Secret | القيمة | إلزامي |
|---|---|---|
| `BOT_TOKEN` | من BotFather | ✅ |
| `ADMIN_ID` | رقمك | ✅ |
| `CHANNEL_ID` | `-100...` | ❌ (اختياري) |
| `SUPPORT_URL` | رابط موقعك (مؤقتاً: أي رابط) | ✅ |
| `DEV_URL` | `https://t.me/Asernoby23` | ✅ |

4. **Actions** → **Scheduler Bot** → **Enable workflow**

### 5. الاستخدام
- افتح البوت في تيليجرام → `/start`
- ابعت ملفات (فيديو، صورة، مستند)
- البوت يضيفها للقائمة
- كل 12 ساعة ينشر واحد تلقائياً

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `/start` | البداية |
| `/queue` | عرض القائمة |
| `/status` | الحالة + الوقت المتبقي |
| `/publish` | نشر فوري |
| `/clear` | مسح القائمة |

## نشر إعلان 30 ثانية
- زر **ادعمني** يفتح موقعك (تحديث `SUPPORT_URL`)
- الموقع يظهر الإعلان 30 ثانية
- **ملاحظة:** البوت لا يعرض إعلانات — الموقع هو المسؤول

## ملاحظات
- **Public repo** مطلوب لاستخدام Actions بلا حدود
- الـ cron كل 15 دقيقة — GitHub قد ي delaying 5-15 دقيقة إضافية
- ملفات الميديا تُحفظ كـ `file_id` (نص فقط) — لا يتم تنزيلها على GitHub
- لمسح البوت نهائياً: احذف المستودع من Settings → Danger Zone
